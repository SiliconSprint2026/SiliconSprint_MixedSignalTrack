# Silicon Sprint: Mixed Signal Design Track

Welcome to the **Mixed Signal Design Track** of **Silicon Sprint**. Please ensure you have the required software installed before starting the problem statements.

---

##  Required Tools & Installation

Participants will need the following tools installed on their machines:
- **LTspice** (by Analog Devices)
- **Audacity**

### Setup Instructions

1. **LTspice**
   - Search for **LTspice (by Analog Devices)** on Google.
   - Open the official Analog Devices download page and select the installer matching your operating system (Windows / macOS).
   - Run the downloaded file and follow the step-by-step installation prompts.

2. **Audacity**
   - Search for **Audacity** on Google.
   - Open the official Audacity download page and select the installer matching your operating system (Windows / macOS / Linux).
   - Run the downloaded file and follow the step-by-step installation prompts.
